# 🔍 QR 框选扫描器 (QR Code Screen Selector)

一款轻量、极简的浏览器扩展。点击图标即可使用鼠标在网页任意区域自由框选二维码，毫秒级提取访问地址。

---

## ✨ 核心特性

- **点一下鼠标框选**：点击扩展图标（或快捷键 `Alt + Q`），全屏自动蒙层变暗，按住左键拖拽即可框选任意大小的二维码。
- **100% 离线隐私安全**：内置 `jsQR` 离线解码引擎，无需将网页或截图上传到任何第三方服务器，保护你的隐私。
- **结果便捷操作**：
  - 自动识别是否为合法 URL 链接。
  - 支持 **一键在新标签页打开**。
  - 支持 **一键复制到剪贴板**。
- **智能容错与引导**：在特殊页面或无权限时提供友好提示，避免无反应。
- **右键菜单扩展**：在网页任意图片上右键，可直接选择「识别图片中的二维码」。

---

## 🚀 安装步骤

1. 浏览器打开 `chrome://extensions/`（Edge 打开 `edge://extensions/`）。
2. 打开右上角 **「开发者模式」**。
3. 点击 **「加载已解压的扩展程序」**。
4. 选择本项目所在的 `qr-scanner` 目录。
5. （可选）如果你经常需要在本地 HTML 文件中扫码，点击该插件卡片中的 **「详细信息」** -> 开启 **「允许访问文件网址」**。

---

## ⌨️ 快捷键

- **唤起框选**：`Alt + Q`（Mac: `Option + Q`）
- **取消框选 / 关闭弹窗**：`Esc` 键 或 单击鼠标右键
